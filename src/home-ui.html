Подключите свой аккаунт

Создайте профиль с отдельной прокси, затем войдите на другом устройстве и передайте код. Все запросы аккаунта будут идти через прокси его профиля.

Состояние подключения

Загружаем состояние…

    Доступ администратора

    Для управления аккаунтами нужен ключ DARIO_ADMIN_TOKEN из файла /opt/dario/deploy/.env на сервере.

    Ключ хранится только в памяти этой страницы. После перезагрузки введите его снова.

    1. Создайте профиль с прокси

    У каждого аккаунта — своя HTTP/HTTPS-прокси. Без неё запросы блокируются. Привязка сохраняется при перезапуске и не меняется во время входа.

    Логин и пароль передаются по HTTPS и хранятся на сервере. Список профилей не раскрывает их. Для другой прокси создайте новый профиль.

    2. Войдите через профиль

    Выберите профиль с прокси.

    Открыть ссылку

    Адрес API для ваших инструментов

    Для запросов используйте отдельный ключ DARIO_API_KEY.

    Вход выполняется на сайте провайдера. На этом сервере браузер не запускается.
