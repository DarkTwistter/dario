Своя прокси для каждого аккаунта

Создайте профиль, укажите прокси и нажмите «Войти». В браузере сервера завершите вход в Claude — аккаунт появится в работающем пуле автоматически.

Токен хранится только в памяти этой страницы. Обычный API-ключ и токен статистики не дают доступ к управлению профилями.

Новый профиль

Для сохранения прежней прокси оставьте все три поля прокси пустыми. Чтобы заменить её, укажите адрес и данные авторизации заново.

У Claude нет собственного пароля. Вход через email-код, ссылку или Google выполняется в отдельном окне браузера.

Профили

Подключитесь с admin-токеном, чтобы увидеть аккаунты.

На Ubuntu откройте эту страницу и noVNC через SSH-туннель. Cookies и сессии каждого профиля хранятся отдельно. При отключении прокси прямого соединения с Claude не выполняется.
